# Learning Spring Boot

Spring Boot kursunda öğrendiklerimi uyguladığım örnek proje. Kurs boyunca Spring Boot'un temel kavramlarını adım adım bu repoda denedim.

> Bu repo bir öğrenme projesidir; üretim amaçlı değildir.

## Kursta Ele Alınan Konular

- Spring Boot 4
- Spring Core, Annotation'lar ve Java Config
- Spring MVC ve Thymeleaf
- Spring REST API geliştirme
- Spring Security
- Spring Data JPA ve Hibernate
- Spring Data REST
- AOP (Aspect-Oriented Programming)
- OpenAPI / Swagger ile API dokümantasyonu
- MySQL ile veritabanı işlemleri
- Maven ile proje yönetimi

## Kullanılan Teknolojiler

| Teknoloji                            | Açıklama                                       |
| ------------------------------------ | ---------------------------------------------- |
| Java 25                              | Programlama dili                               |
| Spring Boot 4.1.1                    | Uygulama çatısı                                |
| Spring Web MVC                       | Controller ve REST/web katmanı                 |
| Thymeleaf (+ Spring Security extras) | Sunucu taraflı HTML şablonları                 |
| Spring Security                      | Kimlik doğrulama ve yetkilendirme              |
| Spring Data JPA / Hibernate          | Veritabanı erişimi (ORM)                       |
| MySQL                                | Veritabanı                                     |
| springdoc-openapi 3.0.1              | Swagger UI ile API dokümantasyonu              |
| Spring Boot DevTools                 | Geliştirme sırasında otomatik yeniden başlatma |
| Maven                                | Derleme ve bağımlılık yönetimi                 |
| IntelliJ IDEA (Community)            | Geliştirme ortamı                              |

## Proje Yapısı

```
learning-spring-boot
├── .mvn/wrapper        # Maven wrapper dosyaları
├── src
│   ├── main
│   │   ├── java        # Uygulama kaynak kodları
│   │   └── resources   # Yapılandırma dosyaları ve Thymeleaf şablonları
│   └── test            # Testler
├── pom.xml             # Maven yapılandırması
├── .gitignore
└── .gitattributes
```
